# Семейный архив: Живая память — AVELI для iOS

Рабочее приложение AVELI, версия 1.0.4 (5), `ru.archiverf.aveli`, iOS 17 и новее. Приложение открывает только действующий рабочий интерфейс `https://archiverf.ru/aveli/connect`. Исходные изображения поставщика сохранены.

Вход проходит через сайт в системном окне `ASWebAuthenticationSession`: общий аккаунт, PKCE S256, зарегистрированный callback `archiverf-aveli://oauth/callback`. Токен аккаунта хранится в Keychain с `WhenUnlockedThisDeviceOnly`. В WebKit передаётся только одноразовый билет в теле POST; сервер создаёт защищённую cookie-сессию. Токены аккаунта и рабочего runtime не передаются в JavaScript, URL или localStorage.

До начала работы нужно разрешить геолокацию при использовании. Координаты отправляются только при открытой работе, каждые 30 секунд; они доступны главному и уполномоченным руководителям. При уходе в фон, завершении работы или отключении доступа работа блокируется, отправляется остановка. Вход, помощь, настройки и выход доступны без GPS. Приблизительная точность отмечается явно. Сервер повторно проверяет текущий доступ и геолокацию при каждом рабочем запросе.

Сборка не содержит локальный WebApp и не запускает EmbeddedWebServer. Эти исходные материалы поставщика сохранены в дереве для происхождения, но исключены генератором проекта. Без связи приложение показывает приостановку работы, а не демонстрационные данные.

## Сборка

На macOS с Xcode 16.4 или стабильным Xcode 26:

```sh
cd StaffApps/AVELI
bash ios/scripts/build-unsigned.sh
```

Скрипт заново создаёт Xcode-проект, собирает arm64 для настоящего iPhone и проверяет метаданные. Результат в `ios/build/artifacts/`: IPA с префиксом `semeynyy-arkhiv-zhivaya-pamyat-`, SHA-256 и сведения о точной ревизии. IPA не подписан: перед установкой требуется подпись AltStore/Sideloadly либо разрешённый профиль Apple. Рабочий workflow находится в `.github/workflows/aveli-ios.yml`; он использует стандартный публичный macOS runner и не публикует релиз.

На Linux можно проверить генерацию проекта, plist, shell и серверный контракт. Это не подтверждает компиляцию Swift или работу разрешений и звонков на физическом iPhone. Для приёмки нужны реальные Xcode-сборки, тест входа, GPS, камеры/микрофона, вложений и отзыва доступа.
