# Atlas

Нативное iOS-приложение для полевой 3D-съёмки, обмеров зданий и цифровизации территорий. Общий интерфейс: графитовая тема, лаймовые акценты, подсказки по состоянию камеры и отслеживания.

Инженерная бета **0.3.1 (4)**, iOS 17+, Swift 6. Исходники включают приложение, переносимое ядро, сервер команд и проверки. Аппаратную камеру, LiDAR, GPS, точность и нагрев необходимо проверять на физическом устройстве; Simulator проверяет интерфейс и 3D-просмотр.

**[Скачать Atlas 0.3.1 (4) для личной установки](https://github.com/alinkarelia/atlasios/releases/download/v0.3.1-preview.4/Atlas-unsigned.ipa)** · [Файлы выпуска и результаты проверок](https://github.com/alinkarelia/atlasios/releases/tag/v0.3.1-preview.4)

Нативная и device-сборки, сервер, ядро и оба полных UI-прогона прошли [одним запуском](https://github.com/alinkarelia/atlasios/actions/runs/38025766341). Реальные кадры первого 3D-открытия, вращения, возврата из фона и прогулки просмотрены вручную на iOS 18.5 и 26.2. IPA требует личной подписи через Sideloadly; аппаратная съёмка ещё требует проверки на iPhone.

## Возможности

- LiDAR через ARKit: предпросмотр до записи, пунктирные контуры обнаруженных плоскостей, контрольные сохранения сетки, восстановление и OBJ самостоятельных сегментов.
- RoomPlan: исходный JSON/USDZ и редактируемый план помещения.
- 3D-просмотр OBJ/USDZ: вращение, масштаб, рёбра и свободная прогулка в границах модели.
- Живая камера JPEG, импорт фото, локальный OCR и геометки. Автоматические координаты можно исправить вручную с сохранением оригинала и истории.
- AR-рулетка, уровень и компас; журнал контрольных обмеров и ручное применение размера к выбранной стене.
- Полигоны территорий, включая участки кладбищ: локальные метры или WGS84, отверстия, категории, карточки и статусы проверки.
- SQLite-проекты, бизнес-раздел с клиентами, заказами, задачами и сметами; экспорт JSON, DXF, GeoJSON, PDF и ZIP исходников.
- Сервер команд: организации, роли, версии и независимая проверка. Передача метаданных запускается оператором.
- StoreKit 2 и серверная проверка Apple: реальные товары и цены требуют настройки App Store Connect.

GPS не совмещает AR-сетку с картой. Независимые AR-сегменты требуют отдельного совмещения. В этой версии нет реконструкции 3D из фотографий, текстурирования mesh, Gaussian splatting или полной автоматической синхронизации исходников. В прогулке камера проходит сквозь стены. Демонстрационная иллюстрация сгенерирована и явно обозначена; тестовая комната — синтетическая геометрия, а не результат обследования.

## Сборка на Mac

1. Откройте `Atlas.xcodeproj` в полном Xcode 16+.
2. Для своей установки выберите Apple Developer Team и подходящий Bundle Identifier в Signing & Capabilities.
3. Выберите схему `Atlas` и устройство. Камера, RoomPlan и LiDAR требуют поддерживаемого физического iPhone/iPad.

```sh
python3 -m pip install 'PyYAML==6.0.3'
python3 Scripts/generate-xcode-project.py --check
bash Scripts/check-native.sh
bash Scripts/build-device-ipa.sh
bash Scripts/check-runtime.sh
```

Готовый Xcode-проект открывается без Python. При изменении источников повторная генерация выполняется командой `python3 Scripts/generate-xcode-project.py`. Переносимое ядро: `cd Packages/AtlasCore && swift test`.

## Бесплатная облачная сборка

[Actions → Verify Atlas and build iPhone candidate](https://github.com/alinkarelia/atlasios/actions) собирает **одну версию исходников** на стандартных GitHub-hosted runners: сервер, ядро и адаптеры, generic Simulator SDK, iPhoneOS Release и полный UI-прогон на iOS 18 и iOS 26. Стандартные runners публичных репозиториев бесплатны по [условиям GitHub Actions](https://docs.github.com/en/billing/concepts/product-billing/github-actions).

Артефакт `Atlas-unsigned-device-IPA-candidate` содержит файл для личной подписи. Сам по себе он не устанавливается и не предназначен для TestFlight. Готовый предварительный выпуск публикуется только после успешного общего прогона и просмотра настоящих изображений 3D-экрана. Снимки и результаты Xcode доступны в артефактах соответствующего запуска.

Инструкция установки с Windows: [iphone-from-windows.md](docs/iphone-from-windows.md). Перед обновлением выгрузите проекты за пределы приложения, сохраните прежние Apple Account, Bundle ID и параметры подписи. Не удаляйте установленную Atlas ради обновления.

## Сервер

```sh
cd Server
npm ci
npm test
npm run build
npm start
```

Node.js 24. По умолчанию локальный сервер; для телефона нужен HTTPS. Настройка: [Server/README.md](Server/README.md). Без настроенной Apple-проверки сервер работает в обозначенном режиме пилота и не выдаёт платные права.
