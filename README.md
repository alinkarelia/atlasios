# TerraView

Бесплатное нативное iOS-приложение для съёмки пространств и объектов, обмеров зданий и цифровизации территорий. Единый графитовый интерфейс с лаймовыми акцентами. Инженерная бета **0.5.0 (7)** прошла все CI-проверки и ручной просмотр снимков iOS 18/26; публикация подготовлена. Результаты и ограничения — в [проверке сборки](docs/verification.md).

## Возможности

| Задача | Реализация |
|---|---|
| Пространство | LiDAR/ARKit: живая камера, яркая заливка записанной поверхности, стабильные контуры, дистанция и подсказки, OBJ и восстановление |
| Отдельный объект | Apple Object Capture: выделение объекта, направляемый обход, дополнительные ракурсы, пауза, оригинальные фото и метаданные; создание настоящего USDZ на совместимом устройстве |
| Помещение | RoomPlan, исходные JSON/USDZ, редактируемые комнаты, стены, размеры, отверстия в контурах |
| Просмотр 3D | Вращение, масштаб, рёбра, свободная прогулка, измерение между двумя точками, горизонтальный срез, PNG текущего ракурса, габариты и площадь треугольников |
| Полевые инструменты | AR-рулетка, уровень, компас, журнал, ручные контрольные размеры и история исправлений |
| Кладбища и территории | Локальные или WGS84-полигоны, отверстия, категории и карточки, источники, статусы проверки |
| Фото | AVFoundation-камера, исходные EXIF при импорте, локальный OCR с ручным подтверждением |
| Геометки | Автоматическое наблюдение с датой/временем/точностью, ручное исправление с сохранением оригинала и истории |
| Экспорт | Исходные OBJ/USDZ, STL, PLY, GLB; JSON, DXF, SVG, GeoJSON, KML, CSV объектов и материалов; PDF плана и ZIP проекта с оригиналами |
| Работа без сети | SQLite, локальные исходники, восстановление записанных черновиков, экспорт без регистрации |

Бизнес-раздел, подписки и StoreKit исключены из приложения. Старые локальные данные и идентификатор `com.atlasfield.app` сохранены для обновления. Исходный репозиторий остаётся закрытым; [публичная копия](https://github.com/alinkarelia/atlasios) используется для бесплатной сборки на стандартных GitHub Actions. Публичность исходников сама по себе не означает открытую лицензию.

## Системы координат и достоверность

Геометка описывает место/время наблюдения и не совмещает локальную 3D-сетку с картой. Независимые AR-фрагменты и RoomPlan-обмеры сохраняют свои системы координат. Импортированным фотографиям не присваивается сегодняшний GPS или вымышленное время съёмки; неизвестные значения остаются пустыми. GPS оператора при Object Capture хранится отдельно от EXIF фотографий.

LiDAR-поверхность показывается после записи checkpoint на диск. Цвет означает записанную геометрию, а не полноту или гарантированную точность обмера. Срез изменяет только просмотр, оригинал сохраняется. Измерение в модели — расстояние по прямой; площадь сетки не равна площади квартиры. Режим прогулки не проверяет столкновения со стенами.

Создание объекта зависит от реальных `ObjectCaptureSession.isSupported` и `PhotogrammetrySession.isSupported`. При недоступной обработке сохраняется набор оригинальных снимков, без сообщения о готовой модели. Просмотр и STL/PLY/GLB сохраняют геометрию без фототекстур; исходный USDZ выгружается полностью. Неизвестные единицы стороннего OBJ не объявляются метрами, а GLB требует установленного метрического масштаба. Ограничения предпросмотра: 64 МБ, 400 000 исходных вершин и 600 000 треугольников.

**x0 и API сервера семейного архива отложены до следующей сборки.** Настраиваемые HTTPS-ссылки и ZIP можно использовать сейчас. Автоматическая очередь работает при активном приложении только с уже настроенным совместимым сервером; ручная отправка — по умолчанию, ограничение Wi-Fi выбирается отдельно. Сервер не требуется для локальных функций. Серверный модуль в исходниках не развёрнут для пользователя.

## Установка и разработка

[Обновление с Windows через Sideloadly](docs/iphone-from-windows.md). Не удаляйте прежнее приложение; подпишите обновление прежним Apple Account с тем же фактическим Bundle ID. Локальные проекты сначала сохраните вне приложения. Этот IPA не подписан для TestFlight.

На Mac нужны Xcode 16.4+ со Swift 6 и iOS SDK; минимальная версия iOS — 17.0. Откройте `Atlas.xcodeproj`, выберите схему `Atlas`, личную команду подписи и устройство. Внутренние имена проекта сохранены для совместимости; домашний экран показывает TerraView и AppIcon.

```bash
python3 -m pip install 'PyYAML==6.0.3'
python3 Scripts/generate-xcode-project.py --check
swift test --package-path Packages/AtlasCore
bash Apps/iOS/Features/Projects/Tests/checks.sh
bash Apps/iOS/Adapters/Tests/checks.sh
python3 Apps/iOS/Adapters/Tests/check-lidar-overlay.py
bash Apps/iOS/Adapters/Tests/mesh-export-checks.sh
bash Apps/iOS/Adapters/Tests/check-field-assembler.sh
bash Apps/iOS/Adapters/Tests/object-capture-checks.sh
```

Нативные проверки: `Scripts/check-native.sh`, `Scripts/check-runtime.sh`, `Scripts/build-device-ipa.sh`. Камера, LiDAR, реконструкция объекта, RoomPlan, GPS и длительная нагрузка проверяются дополнительно на физическом iPhone. [Архитектура](docs/architecture.md) · [Проверка устройства](docs/device-validation.md).
