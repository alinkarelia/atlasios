## Изменения и практические пределы

TerraView 0.8.0 (10) добавляет вход через существующий аккаунт сайта «Семейный архив: Живая память». Логин и пароль вводятся в защищённом окне сайта; приложение не создаёт отдельную учётную запись и не сохраняет пароль.

- Все локальные инструменты, съёмка, карточки, планы, измерения, прогулки и экспорт доступны бесплатно, без заданий и без входа. Задание относится только к дополнительной передаче материалов в команду.
- Передача в задание требует явного выбора задания и обоих согласий, которые требует текущий сервер. Есть отдельная кнопка отключения отправки. Ручной и автоматический режимы, Wi-Fi и очередь сохраняются для исходного аккаунта и назначения; старые материалы не перенаправляются при смене подключения.
- Рабочая геолокация включается оператором отдельно, только если сайт явно сообщил такое требование. Она приостанавливается вне активного приложения; при возврате продолжается, пока режим включён. Кнопка остановки и выход отключают режим на iPhone. Потеря подтверждения положения приостанавливает облачную отправку, сохраняя локальную работу и очередь.
- Исправлены подтверждённые гонки жизненного цикла камеры: поздние записи больше не восстанавливают старую сетку после паузы или закрытия, удалённый якорь не возвращается из фоновой записи, фото не получает идентификатор другого AR-кадра. Кадр камеры принимается только от текущего запуска.

Личная серверная выгрузка без задания пока не реализована. Боевой сервер не изменялся: SSH-соединение из среды сборки недоступно до аутентификации. Авторизованный вход и реальные загрузки на сайт требуют отдельной проверки; автоматические проверки запросов используют ответы-фикстуры. x0 не подключён.

Это инженерная бета для iOS 17+. Собран unsigned iPhoneOS arm64 IPA с именем TerraView и AppIcon. Физические камера, LiDAR, RoomPlan, GPS, точность и длительная нагрузка требуют аппаратной приёмки; Simulator не подтверждает устранение конкретного визуального дефекта на iPhone.

Перед обновлением сохраните важные проекты вне приложения. Не удаляйте Atlas/TerraView. Установите IPA через Sideloadly прежним Apple Account с тем же фактическим Bundle ID. Исходный ID — `com.atlasfield.app`; если Sideloadly изменил его при первой установке, сохраните именно прежнее значение.
