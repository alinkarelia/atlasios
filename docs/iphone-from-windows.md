# Установка Atlas с Windows

Неподписанный IPA требует личной подписи. Обычный Apple Account подходит для личной установки; загрузка в TestFlight требует Apple Developer Program у разработчика, публикующего сборку.

## Обновление

1. В установленной Atlas экспортируйте нужные проекты в ZIP и сохраните вне приложения.
2. Скачайте [Atlas 0.4.0 (5) — `Atlas-unsigned.ipa`](https://github.com/alinkarelia/atlasios/releases/download/v0.4.0-preview.5/Atlas-unsigned.ipa). [Результаты проверки и контрольные суммы](https://github.com/alinkarelia/atlasios/releases/tag/v0.4.0-preview.5).
3. Установите [Sideloadly с официального сайта](https://sideloadly.io/). Требуемые версии iTunes/iCloud для Windows и их ссылки указаны там.
4. Подключите iPhone по USB, разблокируйте его и подтвердите доверие компьютеру.
5. В Sideloadly выберите iPhone, прежний Apple Account и прежние параметры Bundle ID. Исходный идентификатор Atlas: `com.atlasfield.app`; если при первой установке он был изменён, повторите то же значение.
6. Перетащите IPA, нажмите Start. Авторизацию и двухфакторное подтверждение выполняйте на своём компьютере.
7. При необходимости подтвердите доверие профилю: Настройки → Основные → VPN и управление устройством.
8. Если iOS требует режим разработчика: Настройки → Конфиденциальность и безопасность → Режим разработчика, включите, перезапустите iPhone и подтвердите. Этот пункт может появиться только после попытки установки приложения разработчика.
9. Откройте Atlas, проверьте сохранённые проекты, разрешите камеру и по желанию геолокацию. Проверьте съёмку по [чек-листу](device-validation.md).

Если подпись или Bundle ID не совпадают, проверьте настройки до удаления приложения: его локальные данные могут быть потеряны. На бесплатном Apple Account подпись обычно действует 7 дней; повторите установку или настройте автоматическое обновление Sideloadly. Условия аккаунтов: [Apple](https://developer.apple.com/support/compare-memberships/).

GitHub Desktop, iMazing и TestFlight сами по себе не подписывают этот IPA для личной установки.
