# Установка TerraView на iPhone с Windows

TerraView заменяет Atlas. Исходный Bundle ID остаётся `com.atlasfield.app`, чтобы обновление могло сохранить проекты. Приложение бесплатно; Mac и платная Apple Developer Program для установки через Sideloadly не нужны.

Версия **0.5.0 (7)** опубликована после CI и визуальной приёмки. Скачайте [Atlas-unsigned.ipa](https://github.com/alinkarelia/atlasios/releases/download/v0.5.0-preview.7/Atlas-unsigned.ipa) со [страницы TerraView](https://github.com/alinkarelia/atlasios/releases/tag/v0.5.0-preview.7). Размер — **8 390 460 байт**, SHA-256: `c66b07df266c8e656f87bc78ddbf6686e36fb9924b36ccbcc924ed07b9c04c2c`. [Результаты проверки](verification.md).

## Обновить установленный Atlas

1. В старом приложении сохраните ZIP важных проектов за его пределами, например на компьютере.
2. **Не удаляйте Atlas.** Скачайте новый `Atlas-unsigned.ipa` из опубликованного Release TerraView.
3. Подключите iPhone кабелем, разблокируйте и подтвердите «Доверять этому компьютеру».
4. В Sideloadly выберите прежний iPhone и **тот же Apple Account**, которым подписан Atlas. Сохраните прежние параметры Bundle ID. Если Sideloadly изменил его при первой установке, повторите именно тот фактический идентификатор.
5. Перетащите новый IPA в Sideloadly и нажмите **Start**. Совпадающие подпись и идентификатор позволяют установить обновление поверх старого приложения. Если программа сообщает о несовместимости, проверьте аккаунт и параметры; не удаляйте приложение ради повторной попытки.
6. После обновления значок будет называться **TerraView**. Откройте его, проверьте сохранность проектов и выполните короткую съёмку. Уже включённый режим разработчика повторно включать не нужно.

Имя файла `Atlas-unsigned.ipa` и внутренний Bundle ID сохранены для совместимости. Они не определяют имя на домашнем экране.

## Первая установка

1. Установите Sideloadly с [официального сайта](https://sideloadly.io/). Для Windows на его странице указаны необходимые версии iTunes и iCloud от Apple. Sideloadly — сторонний инструмент локальной подписи.
2. Подключите разблокированный iPhone кабелем и подтвердите доверие компьютеру.
3. Выберите устройство, перетащите `Atlas-unsigned.ipa`, укажите Apple Account и нажмите **Start**. Авторизацию и двухфакторное подтверждение выполняйте на своём компьютере; сообщать пароль для облачной сборки не нужно.
4. Если iOS требует режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика**. Включите его, перезагрузите iPhone и подтвердите включение. Если пункт ещё скрыт, сначала завершите сопряжение и попытку установки приложения.
5. Если требуется доверие профилю: **Настройки → Основные → VPN и управление устройством** → ваш профиль разработчика. Затем откройте TerraView.

На обычном бесплатном Apple Account подпись действует **7 дней**. Для продления повторно установите IPA через Sideloadly с теми же аккаунтом и идентификатором либо настройте его автоматическое обновление. Условия и ограничения Apple: [сравнение аккаунтов](https://developer.apple.com/support/compare-memberships/).

## Проверить после установки

Требуется iOS 17 или новее. LiDAR и RoomPlan доступны на совместимых устройствах с LiDAR. Apple Object Capture и обработка Photogrammetry проверяют поддержку отдельно; недоступность обработки не превращает набор снимков в готовую 3D-модель.

Проверьте камеру, короткий скан стен и потолка, сохранение после перезапуска, 3D-просмотр, известный размер рулеткой, геометки и экспорт. Новая визуализация LiDAR и длительная нагрузка требуют физического iPhone; Simulator их не подтверждает. Пошаговый список: [device-validation.md](device-validation.md).

Приложению не нужен сервер для локальной работы. x0 и интеграция семейного архива отложены до следующей сборки. Материалы с оригиналами и паспортом можно передавать ZIP через «Поделиться».

## Облачная пересборка и TestFlight

В [публичном репозитории](https://github.com/alinkarelia/atlasios) workflow **Verify TerraView and build iPhone candidate** собирает настоящий iPhoneOS arm64 IPA без подписи и выполняет полные проверки. Запуск требует права записи в репозиторий. После всех успешных jobs кандидат доступен в **Artifacts → Atlas-unsigned-device-IPA-candidate**; его хранение ограничено 14 днями. Файлы опубликованного Release не зависят от этого срока. Перед выпуском отдельно просматриваются актуальные снимки обеих UI-матриц.

Обычные GitHub-hosted runners публичного репозитория бесплатны по [условиям GitHub Actions](https://docs.github.com/en/billing/concepts/product-billing/github-actions). Закрытый оригинал сохранён, настройки оплаты не менялись.

Для загрузки в TestFlight издателю нужна [Apple Developer Program](https://developer.apple.com/programs/), подпись App Store и запись в App Store Connect. Текущий unsigned IPA предназначен для локальной подписи; он не загружается в TestFlight напрямую. Иконка уже включена в эту версию, подписанная публикация в App Store Connect пока не настроена.
