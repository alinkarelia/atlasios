# Установка Atlas на свой iPhone с Windows

Новая beta — **Atlas 0.4.0 (5)**. IPA собран, проверен и опубликован: **[скачать Atlas-unsigned.ipa](https://github.com/alinkarelia/atlasios/releases/download/v0.4.0-preview.5/Atlas-unsigned.ipa)**. Реальные изображения 3D-просмотра и режимов отправки прошли ручную проверку. Для установки с Windows не нужны Mac и платная Apple Developer Program. Sideloadly подпишет `Atlas-unsigned.ipa` вашим обычным Apple Account и установит его на iPhone.

Пользователь уже установил предыдущую beta и сообщил о чёрном экране съёмки и задержках. В новой версии исправлены подготовка камеры и первоначальное отображение 3D-модели; проверка её камеры, LiDAR, GPS и точности измерений на физическом iPhone ещё требуется. Успешная сборка и запуск симулятора не заменяют такую проверку.

## Обновить уже установленный Atlas

1. В старом Atlas выгрузите ZIP каждого рабочего проекта и сохраните копии вне приложения, например на компьютере.
2. Не удаляйте Atlas. Скачайте новый IPA по инструкции ниже.
3. В Sideloadly выберите тот же iPhone и **тот же Apple Account**, которым подписана старая версия. Сохраните прежний Bundle ID и параметры подписи; исходный Bundle ID приложения — `com.atlasfield.app`. Если при первой установке Sideloadly изменил его, при обновлении повторите прежнее значение.
4. Перетащите новый IPA и нажмите **Start**. Совместимая подпись и идентификатор позволяют устанавливать обновление поверх приложения; резервная копия нужна и при таком обновлении. Если Sideloadly сообщает о несовместимой подписи или идентификаторе, сначала проверьте аккаунт и настройки, не удаляйте приложение ради повторной попытки.
5. Откройте Atlas и проверьте сохранность проектов, затем короткую съёмку и открытие модели. Уже включённый режим разработчика повторно включать не нужно.

Проверенный файл: **0.4.0 (5)**, **6 054 069 байт**, SHA256 **`060c9bfa6247a7697cddd78c95f4aa2e2bd6958ed487d900dbdfa6694668ef27`**. ## Установить на iPhone

1. Установите Sideloadly с [официального сайта](https://sideloadly.io/). Для Windows также нужны версии iTunes и iCloud с сайта Apple, а не из Microsoft Store; ссылки и инструкция находятся на странице Sideloadly. Это сторонний инструмент подписи.
2. Подключите iPhone кабелем, разблокируйте его и подтвердите «Доверять этому компьютеру».
3. Откройте Sideloadly, выберите iPhone, перетащите `Atlas-unsigned.ipa`, укажите свой Apple Account и нажмите **Start**. Авторизацию и двухфакторное подтверждение выполняйте на своём компьютере; для облачной сборки они не нужны.
4. На iPhone откройте **Настройки → Конфиденциальность и безопасность → Режим разработчика**, включите его и выполните предложенную перезагрузку и подтверждение. Если пункт скрыт, сначала завершите сопряжение и попытку установки приложения.
5. Если iOS просит доверие разработчику, откройте **Настройки → Основные → VPN и управление устройством** и подтвердите свой профиль. Затем откройте Atlas.

Требуется iOS 17 или новее. Для LiDAR и RoomPlan нужен поддерживаемый iPhone/iPad с LiDAR; ручные инструменты доступны и без него.

На бесплатном аккаунте подпись действует **7 дней**. Затем повторите подпись и установку через Sideloadly либо настройте его автоматическое обновление: для него должны быть доступны компьютер с работающим фоновым сервисом и iPhone по USB или настроенному Wi-Fi. Apple ограничивает число личных приложений и App ID; ограничения описаны в [сравнении аккаунтов Apple](https://developer.apple.com/support/compare-memberships/). Перед обновлением или удалением Atlas выгружайте ZIP проекта за пределы приложения.

После установки или обновления проверьте сохранение проекта после перезапуска, разрешения камеры и GPS, короткий скан, рулетку по известному размеру, ручную поправку геометки и экспорт. Для передачи откройте «Материалы и отправка», подготовьте ZIP и проверьте «Поделиться». Полный список — [device-validation.md](device-validation.md). Для версии 0.4.0 эти аппаратные и полевые проверки ещё предстоит выполнить.

## Если нужно пересобрать приложение

**В облаке:** в [публичном репозитории Atlas](https://github.com/alinkarelia/atlasios) откройте **Actions → Verify Atlas and build iPhone candidate → Run workflow**. Запуск workflow требует права на запись; скачать Actions artifact можно после входа в GitHub. Дождитесь успешного завершения всех jobs и скачайте `Atlas-unsigned-device-IPA-candidate` в **Artifacts**. Workflow собирает настоящий iPhoneOS Release без подписи и выполняет серверные, нативные и полные UI-проверки на двух версиях iOS. Apple Account и сертификаты для облачной сборки не нужны.

Перед выпуском нового кандидата отдельно просмотрите настоящие изображения первого 3D-кадра, вращения, возврата из фона, прогулки и ручного/автоматического режима передачи из обоих runtime artifacts. Зелёная сборка сама по себе не подтверждает качество изображения или работу физических датчиков.

Стандартные GitHub-hosted runners в публичных репозиториях бесплатны по [условиям GitHub Actions](https://docs.github.com/en/billing/concepts/product-billing/github-actions). Закрытый оригинал сохранён: его бесплатная месячная квота ранее была исчерпана, поэтому текущая сборка выполняется из отдельного публичного снимка исходников. Настройки оплаты не менялись. Larger runners оплачиваются отдельно; текущий workflow использует обычные runners.

**На доступном Mac:** установите полноценный Xcode с iPhoneOS SDK, откройте Terminal в папке исходников `atlas` и выполните:

```bash
python3 -m venv /tmp/atlas-build-env
source /tmp/atlas-build-env/bin/activate
python3 -m pip install 'PyYAML==6.0.3'
bash Scripts/build-device-ipa.sh
```

После успешной сборки передайте на Windows файл `artifacts/device-preview/Atlas-unsigned.ipa`. Для самой сборки не нужны ваш Apple Account и подключённый iPhone.

## Если нужен именно TestFlight

TestFlight бесплатен для тестировщика. Для загрузки Atlas нужны активная [Apple Developer Program](https://developer.apple.com/programs/), подпись App Store и запись приложения в App Store Connect. Внутреннее тестирование доступно участникам App Store Connect с доступом к приложению; для внешней группы Apple проводит бета-проверку. Режим разработчика для TestFlight не нужен.

Текущий IPA предназначен для локальной подписи, загрузка в TestFlight не настроена. Перед ней ещё нужно подготовить AppIcon и подписанную сборку для App Store Connect. Продукты подписки потребуют отдельной настройки в App Store Connect.
