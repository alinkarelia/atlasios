# TerraView → семейный архив: передача разработки

Этот комплект нужен, чтобы встроить загрузку и обработку материалов TerraView в **существующий сервер семейного архива**. Исходная версия кода: `531f36191c01fd7b62f7f4da01e54ff3b89aafcd` репозитория `alinkarelia/atlasios`.

Сначала проверьте манифест и SHA-256 приложенного архива. Затем прочитайте [API-MAPPING.md](API-MAPPING.md), `Server/src/app.ts`, `Server/src/materials.ts`, `Server/src/collaboration.ts` и `docs/COLLABORATIVE-MOSAIC.md`.

Подтверждённый результат backend: TypeScript проходит проверку; **84 серверных теста прошли**, включая 18 тестов совместной работы. Проверены 8 настоящих экспортов синтетических планов из Swift — 182 ячейки. Это проверка контракта и математики, а не полевой тест пяти телефонов. Полная CI-проверка этого же Git-коммита завершилась успешно: все 6 заданий; по 18 UI-тестов на iOS 18.5 и 26.2. Ручная проверка 72 изображений ещё не завершена; выпуск 0.7 пока не опубликован.

Сервер TerraView не развёрнут. Адрес, технология, схема пользователей и API семейного архива неизвестны. x0 не подключена; установленного обработчика мозаики нет. В таком состоянии обработка возвращает `503 processor_unconfigured`, а фрагменты сохраняются раздельно. Локальная производная OBJ и серверная фотограмметрия — разные возможности.

Для передачи нужны весь `Server/` с исходниками, тестами и lock-файлом; весь `Packages/AtlasCore/`; нативные адаптеры передачи, журналов и экспорта; документация. Исключите `node_modules/`, `dist/`, рабочие базы/материалы, `.env`, токены и иные секреты. Тестовая геометрия и публичный тестовый сертификат не являются рабочими пользовательскими данными.

## Текст для другого чата

> Продолжаем интеграцию TerraView с уже существующим семейным архивом. Приложены проверяемые исходники версии 531f36191c01fd7b62f7f4da01e54ff3b89aafcd, манифест и инструкции START-HERE.md/API-MAPPING.md. Сначала изучи существующий репозиторий сайта, его авторизацию, хранилище и фоновые задания. Встрой совместимый адаптер в этот сервер; сохрани его стек и пользователей. Не запускай второй независимый сервер и отдельную базу аккаунтов без обоснованной необходимости. Обеспечь отображение account/organization/project UUID, права сотрудников, неизменяемые исходники, передачу частями с SHA256 и возобновлением, CAS/идемпотентность, журнал покрытий и проверяемую регистрацию фрагментов. Разные frameID не совмещай только по GPS. Подключение x0 делай после изучения её реального входного/выходного контракта; API-ключ хранится только на сервере. Нельзя объявлять обработку успешной без прочитанных и проверенных исходников и настоящего отдельного результата. Сначала реализуй и проверь интеграцию, затем подготовь конкретный результат для развёртывания. Отсутствующие адреса и доступы установи из окружения проекта, не выдумывай их. Текущие 84 backend-теста — подтверждённая исходная база; новый сайт и будущий обработчик требуют собственных проверок.
